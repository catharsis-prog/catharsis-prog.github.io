## Как устроен учебник

Каждый модуль — это от четырёх до девяти уроков и практикум в конце. Уроки небольшие: их можно прочитать за один вечер и сразу что-то написать руками.

**Каждый урок** состоит из четырёх частей:

1. **Теория.** Объяснение простым языком, с примерами из жизни и кодом.
2. **Микрозадачи.** Одна-две небольшие задачи с разбором прямо в тексте.
3. **Самостоятельная задача.** Похожая задача без ответа — проверка на понимание.
4. **Практикум модуля.** Шесть-восемь задач посложнее. Разборы — отдельной страницей, чтобы вы сначала попробовали сами.
